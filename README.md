# IELTS Writing Practice Master

An interactive web application for IELTS Writing Task 1 and Task 2 preparation.

## Features
- **Task 1 & Task 2 Modes:** Supports Academic graphs, General Training letters, and Task 2 essays.
- **Configurable Timer:** Standard 20m/40m presets, custom duration, or untimed mode.
- **Real-time Word & Metric Counter:** Live progress bar tracking minimum targets (150/250 words) with sentence and paragraph metrics.
- **Built-in IELTS Reference Tools:** Essay structure templates, linking vocabulary bank, and marking rubric guidelines.
- **Local Storage Drafts:** Save and reload previous practice attempts.
- **PDF Export:** Export your finished practice essay into a PDF document.

## How to Deploy on GitHub Pages
1. Extract `ielts-writing-practice.zip`.
2. Create a new GitHub repository named `ielts-writing-practice`.
3. Upload `index.html` and `README.md` to your repository root.
4. Go to **Settings** > **Pages** > Select branch `main` and save.
